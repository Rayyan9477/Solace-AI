## Files
- `services/therapy_service/src/infrastructure/repository.py`: the four in-memory repositories now call
  `_refuse_in_strict_environment()` (`is_strict_environment()`, so staging as well as production) and raise
  `RuntimeError("In-memory repositories are not allowed in strict environments.")`. `UnitOfWork` takes
  `backend: Literal["postgres", "memory"]` (default `memory`, keeps existing positional callers working) and exposes

  - `ImportError`/`KeyError` while building Postgres: strict raises

  `memory` and `settings.environment` is not `test`; otherwise `(True, <backend>)`.
