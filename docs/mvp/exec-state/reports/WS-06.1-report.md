### The new guard (three tests)
**Scan scope.** Every `.py` module under `src/solace_events` and `services/*/src`: 209 modules today. It parses each one with `ast`. A third test, `..._scans_the_event_plane_and_every_service`, pins the scope (postgres_stores.py, publisher.py and all seven MVP services are present), so the guard cannot pass vacuously.

**The write-site regex.** The pattern is:
```
\binsert\s+into\s+QUAL"?event_outbox\b | \bcopy\s+QUAL"?event_outbox\b
| \bcopy_(?:records_)?to_table\s*\(\s*(?:table_name\s*=\s*)?['"]event_outbox\b
```
- It is case-insensitive, and the whitespace classes span newlines.
- `QUAL` is an optional, optionally quoted schema qualifier: `public.` or `"public".`.
- It also matches a SQL `COPY event_outbox`, and the copy helpers with the table as a positional or `table_name=` argument.
