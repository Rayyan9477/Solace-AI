## Deviations
1. **Strict ports use `!override`, not `!reset`.** In Compose, `!reset` with a value drops the key (the strict render had no `ports`, a KeyError). `!override` replaces the list, which is the brief's intent.
2. **The never_routed matcher is `/x /x/*` instead of `/x*`.** The brief's adapt test asserts the literal `"/metrics"` in the JSON. Exact plus subpath patterns cover every real route, and I added `/api/v1/internal` (no slash).
3. **Registry shape for the site addresses.** One row per (name, service) is enforced, so caddy's `CADDY_API_SITE`/`CADDY_AUTH_SITE` rows use source `DOMAIN` (strict truth: they are `api.`/`auth.${DOMAIN}`). Separate `compose` pseudo-service rows, dev only, register the `CADDY_*_SITE` interpolation sources so that `.env.example` documents them.
