## Concerns

1. **Out-of-scope edit: `scripts/ci/dockerfiles.py::uvicorn_flags` (WS-01.5).** The old body returned only the `--` tokens, so the brief's probe test could never start uvicorn: values were dropped, and with values kept the image's `--host 0.0.0.0 --port 8000` would override the test's own socket. The new contract returns the uvicorn options with their values, minus the bind address; an option's value is the next argument unless that argument is itself an option. No other caller exists (grep). WS-01.5 is finished, and no parallel lane touches this file.
2. **Out-of-scope edit: plan conflict between WS-01.5's `test_mvp_248` (`assert "||" not in text`) and this brief's verbatim HEALTHCHECK `... || exit 1`.** I kept the HEALTHCHECK verbatim, because the caller asked for verbatim values. I narrowed the WS-01.5 assertion to exempt only lines that start with `HEALTHCHECK`, so an install fallback in any RUN, CMD or ENTRYPOINT still fails it. Alternative if preferred: drop `|| exit 1` (moby treats any non-zero probe exit as unhealthy) and revert the test edit.
3. **`/live` does not exist yet in user-service, notification-service or analytics-service.** The other six define it. The image HEALTHCHECK will report these three unhealthy as soon as compose stops overriding it with `/health` (R-01.1, WS-03). WS-04's `solace_infrastructure/runtime/health.py` (`LIVE_PATH`) presumably provides it; confirm the order.
4. **`--proxy-headers` is already uvicorn's default and is effectively a no-op behind Caddy.** Uvicorn trusts X-Forwarded-* only from `--forwarded-allow-ips` (default 127.0.0.1), and Caddy reaches the services from a non-loopback container IP. Client IPs (rate limiting, audit) will be Caddy's until `FORWARDED_ALLOW_IPS` is set to the edge network (WS-03/WS-07).
5. **Semantics I chose where the contract is silent** (WS-03.2/03.7 and WS-04.11 should know):
   - "set" means defined: an empty `NAME` next to `NAME_FILE` is fatal, and an empty `NAME_FILE` is fatal because it names a missing file.
   - An empty file exports an empty value; ProductionGuards decides whether that is acceptable.
   - A CRLF file keeps its CR.
   - Only `SSL_CERT_FILE` is exempt. Any other platform path variable ending in `_FILE` (for example `AWS_CONFIG_FILE`, `PIP_CONFIG_FILE`) would be treated as a secret reference, and a missing target is fatal. None is set anywhere today (grep of services, src, deploy and compose).
6. **The entrypoint is owned by appuser**, as the brief's `--chown=appuser:appuser` requires, like the rest of /app. root:root 0755 would stop the app process rewriting it for the next restart of the same container. This is optional hardening, not done, because the value is verbatim.
7. **`--log-level warning` also hides uvicorn's own INFO startup, lifespan and WebSocket open/close lines.** The app's structlog output is unaffected (it was verified at info during the boot probe). Operators who want uvicorn lifecycle lines must get them from the app's logs.
8. **Docker resources.** `python:3.12-slim@sha256:b18b261e...` was not in the local image store, so I pulled it for the realinfra tests. It and `solace/orchestrator-service:ws01-6` were removed at the end; any test container was removed by the test's `finally`. The realinfra tests pull the base image again when it is absent.
9. The brief's Step 6 label is `WS-01.6:done`; I used the caller's `WS-01.6:head`.
